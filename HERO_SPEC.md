# Hero Section — Malika Atelier

## Концепция
Luxury-ателье. Слоган: **«Дорого. Долго. Шикарно.»**
Девушка в алом платье — главный визуальный акцент, центр кадра полностью свободен.

## Анимации

### Последовательность (от 0 до ~3s)

| Время | Элемент | Эффект |
|-------|---------|--------|
| 0.0s | Фото | `opacity 0→1` + `scale 1.08→1`, 2.4s |
| 0.55s–0.9s | M·A·L·I·K·A | каждая буква падает сверху (`translateY(-22px)→0`), stagger 0.065s |
| 1.05s | Разделитель | `scaleX 0→1` из центра |
| 1.2s | «Индивидуальный пошив» | `translateY(110%)→0`, overflow:hidden маска |
| 1.55s | «Дорого.» | `translateY(110%)→0`, overflow:hidden маска |
| 1.75s | «Долго.» | то же |
| 1.95s | «Шикарно.» | то же |
| 2.15s | CTA кнопка | `translateY(110%)→0`, overflow:hidden маска |
| 2.8s | Золотой блик | одиночный sweep 90° через слоган, 1.4s |

Все ease: `cubic-bezier(0.19, 1, 0.22, 1)` (exponential out — похоже на GSAP expo).

### Hover CTA
Золотая заливка влезает слева (`translateX(-102%)→0`), текст меняется на тёмный.

### Parallax при скролле
Фон двигается `translateY(0→16%)` пропорционально скроллу, через `requestAnimationFrame`.

## Оверлей
- Сверху: `rgba(10,5,0,0.88) → transparent` (первые 30% высоты)
- Снизу: `rgba(10,5,0,0.88) → transparent` (последние 30% высоты)
- Центр: полностью прозрачен — девушка не перекрыта
